# www.cwift.net: Cwift.net, desktop appraisals in 24 hours

Minimal companion to cwift.com; a Brian Ward Appraisal service. `public/` is the Cloudflare Pages output directory;
`functions/api/` holds order.js, upload-photos.js and form-token.js. Generated by `_tools/build.py` in the iCloud project folder.
Pages: framework None, no build command, output `public`. Env vars as cwift.com (RESEND_*, FORM_SECRET, TURNSTILE_SECRET_KEY, GOOGLE_*).

Pages: home, `/uses` (twelve uses in plain English), `/areas` and 207 area pages at `/areas/<slug>`, `/credible`, `/questions`,
`/about`, `/order`, `/upload`, `/privacy`, plus llms.txt and llms-full.txt. Area facts: `_tools/generator/areas/master.json`;
area copy: `areas/net_b1.json`..`net_b8.json`; photo pools: `areas/images_net.json` with the photos in `images_src/images/areas/`.
Rebuild: `cd _tools/generator && TURNSTILE_SITEKEY=<cwift.net site key> python3 build.py <out_dir>`, then copy `<out_dir>/public`
over `public/` and add the credibility PDF. The area copy pipeline lives in the cwift.com project folder, `_tools/area_pipeline/`.
