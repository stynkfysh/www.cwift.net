# www.cwift.net: Cwift.net, desktop appraisals in 24 hours

Minimal companion to cwift.com; a Brian Ward Appraisal service. `public/` is the Cloudflare Pages output directory;
`functions/api/` holds order.js, upload-photos.js and form-token.js. Generated by `_tools/build.py` in the iCloud project folder.
Pages: framework None, no build command, output `public`. Env vars as cwift.com (RESEND_*, FORM_SECRET, TURNSTILE_SECRET_KEY, GOOGLE_*).
